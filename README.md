# V//F — WEB//OPS Portfolio

Portfólio pessoal de **Vinicius Franck**, criado para reunir minha trajetória profissional, projetos, estudos e evolução nas áreas de infraestrutura, automação, observabilidade, inteligência artificial e cybersecurity.

A identidade visual do projeto segue o conceito **WEB//OPS**: uma mistura de infraestrutura, redes, nodes, automação e interfaces de sistema.

## Sobre o portfólio

Mais do que uma página de apresentação, a ideia deste projeto é mostrar como diferentes áreas da tecnologia fazem parte do mesmo ecossistema.

Minha trajetória começou no suporte técnico e evoluiu para infraestrutura corporativa, administração de ambientes Microsoft, redes, segurança e automação.

Atualmente também desenvolvo projetos próprios envolvendo observabilidade, inteligência artificial e cybersecurity.

## Projetos em destaque

### Central de Automação

Plataforma criada para centralizar ferramentas e rotinas de infraestrutura em uma única interface.

Entre os módulos atuais estão:

- automação de usuários no Active Directory;
- auditoria de rede;
- monitoramento UniFi;
- registro de operações;
- evolução para monitoramento e observabilidade.

Roadmap atual:

`Infrastructure → Collectors → Metrics → Grafana → Dashboards / Alerts`

### ForgeMindAI

Plataforma de **Enterprise Decision Intelligence** voltada à análise de dados empresariais com apoio de Inteligência Artificial.

O projeto explora:

- análise de planilhas e documentos;
- agentes de IA;
- Data Governance;
- Risk Assessment;
- Business Intelligence;
- Executive Insights;
- automação de análises.

### Cybersecurity Lab

Ambiente pessoal de estudos e experimentação em cybersecurity.

Atualmente estudando:

- Kali Linux;
- fundamentos de Ethical Hacking;
- Network Enumeration;
- Vulnerability Analysis;
- segurança de redes.

## WEB//OPS

A identidade visual foi criada em torno de quatro pilares:

```text
NETWORK.
AUTOMATION.
INTELLIGENCE.
SECURITY.
```

O site utiliza nodes, conexões e topologias como elementos visuais para representar a relação entre infraestrutura, redes e tecnologia.

Também possui:

- dark mode e light mode;
- network canvas interativo;
- boot screen;
- console visual;
- mapa de projetos;
- animações de interface;
- easter eggs.

## Executando localmente

O projeto é totalmente estático.

Clone o repositório:

```bash
git clone https://github.com/Franck-686/portfolio.git
```

Entre na pasta:

```bash
cd portfolio
```

Abra o `index.html` diretamente no navegador ou utilize uma extensão como **Live Server** no VS Code.

Não é necessário instalar dependências.
